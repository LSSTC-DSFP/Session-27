The twenty-seventh session of the LSST-DA Data Science Fellowship Program focuses on time-series analysis.

- Dr. Sabina Sagynbayeva, McGill [:octocat:](https://github.com/ssagynbayeva)

- Dr. Adam Miller, Northwestern | CIERA [:octocat:](https://github.com/adamamiller)
- Dr. James Johnson, CIERA [:octocat:](https://github.com/giganano)
